# FinConverter

Telegram-бот для студентов: присылаешь фото конспектов, сканы или PDF — получаешь один аккуратный PDF.
К боту прилагается мини-апп, где можно поменять порядок страниц, повернуть их и выбрать режим «Скан».

## Что умеет

- **Фото → PDF.** Пришли фото по одному, альбомом или файлом (так качество выше). Бот отвечает одним сообщением «В PDF уже N стр.», а не спамит на каждое фото.
- **Склейка PDF.** Пришли несколько PDF (можно вперемешку с фото) — получишь один файл в нужном порядке.
- **Режим «Скан».** Убирает тени и неровный свет, фон становится белым, текст контрастнее. Плюс отдельный режим «Ч/Б».
- **A4 с полями или «как фото».** В режиме A4 все страницы одного размера, как у нормального документа.
- **Три уровня качества.** «Сжатое» подходит для порталов с лимитом на размер файла.
- **Название файла.** Просто напиши текст в чат или укажи его в мини-аппе.
- **Титульный лист** Финансового университета: тип работы, дисциплина, тема, студент, группа, преподаватель. Лист вставляется первой страницей (A4, Times New Roman 14, поля по ГОСТ 7.32). ФИО, группа и дисциплина запоминаются, тема сбрасывается после каждого PDF. В мини-аппе видно живое превью.
- **Мини-апп «Объектив»:** страница крупно с листанием, плёнка миниатюр (долгое нажатие — перестановка), поворот, удаление с возвратом, режимы Цвет / Ч/Б / Скан, шторки настроек и титульного листа, проверка распознанного текста. Шрифт Golos Text, жёлтый акцент. Светлая и тёмная тема переключаются вслед за темой Telegram.
- **Распознавание текста в мини-аппе.** Кнопка «Aa»: бот распознаёт фото (печатный текст, русский и английский) и, если задан `ANTHROPIC_API_KEY`, тут же проверяет текст моделью Claude. Ошибки распознавания, правописание и пунктуация исправляются сами, спорное по смыслу только предлагается; любую правку можно вернуть, а переключатель «Оригинал» показывает текст как распознан. Человек проверяет и правит текст постранично, по нажатию на правку фото приближается к слову. В конце на выбор документ Word (Times New Roman 14, поля по ГОСТ), PDF из текста или копирование.
- **Распознавание текста командой `/ocr`.** Невидимый текстовый слой на фото: по PDF работают поиск и копирование. Печатный текст на русском и английском (Tesseract), рукописный читается плохо. Файл почти не растёт. В боте включается командой `/ocr`, настройка сохраняется. Распознаются только фото, PDF-файлы остаются как есть.
- Понимает HEIC с iPhone, PNG с прозрачностью и EXIF-поворот.

Команды: `/pdf` собирает файл, `/title` показывает и включает титульный лист, `/clear` начинает заново, `/help` показывает подсказку. Скрытая команда `/update` обновляет бота на сервере из git, только для админов (см. «Деплой»).

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN и WEBAPP_URL
.venv/bin/python -m app.main
```

Один процесс одновременно опрашивает Telegram (long polling) и поднимает веб-сервер мини-аппа на `PORT`.

Telegram открывает мини-апп только по **HTTPS**. Для разработки достаточно туннеля:

```bash
cloudflared tunnel --url http://localhost:8080
```

Полученный `https://….trycloudflare.com` нужно вписать в `WEBAPP_URL` и перезапустить бота. Кнопка «Редактор» появится в меню бота сама.
В BotFather мини-апп регистрировать необязательно: кнопки `web_app` работают и так.

**Посмотреть интерфейс без Telegram и без токена:** запусти `.venv/bin/python -m app.demo` и открой `http://localhost:8080/?demo`. Там фейковые страницы, бот не запускается. На широком экране мини-апп показывается в рамке телефона 390×844, рядом кнопка смены темы. Без рамки, на всю ширину: `?demo&inner`.

Аватарка для BotFather (`/setuserpic`) лежит в `assets/bot-avatar.png`, логотип — в `assets/logo.svg`.

## Деплой

```bash
git clone <репозиторий> /opt/finconverter && cd /opt/finconverter
cp .env.example .env     # BOT_TOKEN, WEBAPP_URL, ADMIN_IDS
docker build -t finconverter .
docker run -d --name finconverter --restart unless-stopped -p 127.0.0.1:8082:8080 \
  --env-file .env -v finconverter-data:/data -v /opt/finconverter:/app finconverter
```

`WEBAPP_URL` — публичный HTTPS-адрес, который проксирует на порт контейнера (nginx/Caddy с сертификатом). Состояние проекта и следующие шаги — в [CLAUDE.md](CLAUDE.md).

### Закрытый режим

Пока бот закрытый: пользоваться им и мини-аппом могут только id из `ADMIN_IDS`. Остальным бот отвечает «Бот пока работает в закрытом режиме», а мини-апп показывает экран «пока закрыт» (API отдаёт 403). Если `ADMIN_IDS` пуст, закрыто для всех, и бот на любое сообщение подсказывает id отправителя, чтобы вписать его в `.env`. Чтобы открыть бота всем, нужно убрать проверку в `app/bot.py` (`admin_only`) и `app/web.py` (`auth_middleware`).

### Обновление командой `/update`

Клон репозитория монтируется в контейнер как `/app` (`-v /opt/finconverter:/app`). Админ пишет боту `/update`: бот делает `git pull --ff-only`, доставляет зависимости, если изменился `requirements.txt`, и перезапускается. Перезапуск делает Docker (`--restart unless-stopped`), после старта бот пишет «Бот перезапущен. Версия: …». Обновляется ветка, на которой стоит клон. Если менялись `Dockerfile` или системные пакеты, образ придётся пересобрать вручную.

- Список админов: `ADMIN_IDS=123456789` в `.env` (id через запятую). В список команд бота `/update` не попадает.
- Серверу нужен доступ на чтение репозитория: публичный репозиторий или deploy key (`git config core.sshCommand "ssh -i … -o IdentitiesOnly=yes"` в клоне, ключ тоже монтируется в контейнер).
- Образ нужно пересобрать один раз, чтобы в нём появился git. Дальше пересборка нужна только при смене `Dockerfile`.
- Вне Docker (`dev.sh`) `/update` подтянет код и завершит процесс, поднимать его снова нужно самому.

## Устройство

```
app/
  main.py     запуск бота и веб-сервера
  bot.py      хендлеры aiogram: фото, документы, кнопки, команды
  web.py      API мини-аппа и проверка подписи initData
  service.py  сборка + отправка PDF (общее для бота и мини-аппа)
  pdf.py      обработка изображений и сборка PDF (Pillow + pypdf)
  ocr.py      распознавание (Tesseract), очередь, невидимый текстовый слой
  recognize.py  фоновое распознавание страниц для мини-аппа
  document.py  Word и PDF из распознанного текста
  title.py    титульный лист (reportlab)
  storage.py  сессия пользователя на диске: data/<user_id>/
webapp/       мини-апп: vanilla JS, SortableJS, Telegram WebApp SDK
```

- Мини-апп авторизуется заголовком `X-Init-Data`. Сервер проверяет подпись HMAC по токену бота. Превью страниц отдаются по подписанным ссылкам.
- После отправки PDF сессия очищается, а выбранные настройки (режим, формат, качество) сохраняются.
- Ограничения Telegram: бот скачивает файлы до 20 МБ и отправляет до 50 МБ. Если PDF получился больше, бот предложит выбрать «Сжатое» качество.

## Идеи на следующие версии

1. **Автообрезка документа.** Находить края листа на фото и выравнивать перспективу (OpenCV), чтобы получался настоящий скан без стола вокруг.
2. **OCR для рукописного текста** (облачное распознавание) и выгрузка текста файлом `.txt`/`.docx`. Печатный текст и PDF с поиском уже есть.
3. **Сжатие под лимит.** Например: «уложи в 10 МБ». Бот сам подбирает качество.
4. **Разделить или извлечь страницы** из PDF, а также PDF → JPG.
5. **Word/PowerPoint → PDF** через LibreOffice headless.
6. **Групповой режим.** Бота добавляют в чат группы, каждый кидает свои фото, на выходе общий конспект.
7. **История** последних 10 PDF с повторной отправкой.
8. **Водяной знак или нумерация страниц** внизу листа.

## Перед продом

- Титульному листу нужен шрифт Times New Roman или Liberation Serif. На Linux: `apt install fonts-liberation`. Можно указать свои пути в `TITLE_FONT` и `TITLE_FONT_BOLD`.
- Шапку титульника (название вуза) стоит сверить с методичкой своего департамента. Она задаётся в `UNIVERSITY` в `app/title.py`.

- Хранилище сейчас на диске. Для нескольких инстансов нужно перейти на Redis/S3 и добавить очистку старых сессий (например, cron, который удаляет `data/*` старше суток).
- Проверка текста моделью: нужен `ANTHROPIC_API_KEY` (ключ API на console.anthropic.com, платный, отдельно от подписки Claude), `PROOFREAD_MODEL` по умолчанию `claude-haiku-5-5`. Модель получает только текст страницы, фото остаются на сервере. Страница обходится в доли цента. Без ключа или при сбое остаётся обычный распознанный текст.
- Распознавание текста: `OCR_WORKERS` страниц считаются одновременно (по умолчанию 2), остальные сборки ждут в очереди и видят своё место в сообщении. Лимит `OCR_DAILY_PAGES` (по умолчанию 100) страниц в сутки на человека, админам он не действует, сутки считаются по UTC. Образ ставит `tesseract-ocr` с русским и английским.
- Нагрузка: `BUILD_WORKERS` (по умолчанию 2) PDF собираются одновременно, остальные ждут. Фото при загрузке разбираются в потоках и не блокируют бота. `MAX_PAGES` (300) страниц в одном PDF. Сессии, которых не трогали `SESSION_TTL_DAYS` (7) дней, удаляются раз в 6 часов, запомненные ФИО остаются.
- Тяжёлая обработка изображений идёт в `asyncio.to_thread`. При большой нагрузке её лучше вынести в очередь (arq/celery).
