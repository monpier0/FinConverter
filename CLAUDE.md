# FinConverter — контекст для продолжения работы

Telegram-бот с мини-аппом для студентов Финансового университета («финашка»):
человек присылает фото конспектов, сканы или PDF, бот собирает из них один PDF.
Пользователь общается по-русски, отвечать тоже по-русски.

## Что уже сделано (на 30.10.2026)

- **Бот** (`app/bot.py`, aiogram 3, long polling): фото по одному, альбомом или файлом
  (JPG/PNG/HEIC), склейка PDF. На альбом бот отвечает одним обновляемым
  сообщением «В PDF N стр.», а не на каждое фото. Текстовое сообщение становится
  именем файла. Команды: `/pdf`, `/title`, `/ocr`, `/clear`, `/help`.
- **Сборка PDF** (`app/pdf.py`): режимы «Цвет / Ч/Б / Скан» (скан убирает тени,
  фон становится белым), формат «как фото / A4 с полями», три уровня качества.
  Учитывается лимит Telegram: бот отправляет до 50 МБ, скачивает до 20 МБ.
- **Титульный лист** (`app/title.py`, reportlab): шаблон Финансового университета,
  A4, Times New Roman 14, поля по ГОСТ 7.32. ФИО, группа и дисциплина
  запоминаются (`data/_titles/<uid>.json`), тема и переключатель сбрасываются
  после каждого PDF. Нужен шрифт Times New Roman или Liberation Serif.
- **Мини-апп** (`webapp/`, vanilla JS + SortableJS): сетка страниц с
  перетаскиванием, просмотр со свайпом, поворот, удаление, чипсы настроек
  (внутри — нативный `<select>`), шторка титульника с живым HTML-превью
  (копия вёрстки `title.py` на `cqw`), шторка имени файла, экраны «пусто» и
  «готово». Своя плавающая панель снизу, MainButton Telegram не используется.
- **API мини-аппа** (`app/web.py`, aiohttp в том же процессе, что и бот):
  авторизация по подписи `Telegram.WebApp.initData` (HMAC от токена), превью
  страниц по подписанным ссылкам.
- **Деплой и `/update`**: бот на VDS (Ubuntu 24, Амстердам, Docker + Caddy) по адресу
  `finconverter.194-41-113-226.sslip.io` (контейнер на `127.0.0.1:8082`; на сервере ещё два
  чужих бота и `starosta` на порту 8000, их адрес `194-41-113-226.sslip.io` не трогать).
  `/update` (`app/updater.py`, только `ADMIN_IDS`) делает `git pull --ff-only` в смонтированном
  клоне `/opt/finconverter` и перезапускает процесс, Docker поднимает его снова.
  `PROXY_URL` нужен, если Telegram недоступен напрямую (локально из РФ).
  **Закрытый режим**: пока ботом и мини-аппом могут пользоваться только `ADMIN_IDS`
  (`admin_only` в `app/bot.py`, `auth_middleware` в `app/web.py`, экран «пока закрыт» в
  мини-аппе). При пустом `ADMIN_IDS` закрыто для всех.
- **Распознавание текста** (`app/ocr.py`, только печатный текст, rus+eng): невидимый
  текстовый слой поверх фото, файл почти не растёт. Опция `ocr` в `BuildOptions`, в боте
  включается `/ocr`. Очередь (`OCR_WORKERS`, по умолчанию 2), прогресс «Распознаю текст: N из M
  стр.» в сообщении сборки, лимит `OCR_DAILY_PAGES` (100/сутки на человека, админам нет).
  **В мини-аппе переключателя пока нет**: по правилу 6 сначала макет (чипса «Распознать текст»,
  состояния «в очереди / распознаю», экран «готово»). Рукопись нужна позже отдельным
  облачным режимом. Тест: Tesseract 5.3, прогнаны очередь, лимит, прогресс, `pdftotext`.
- **Логотип**: лист с загнутым уголком цвета лайм, строки на нём образуют F
  (`assets/logo.svg`, аватарка для BotFather — `assets/bot-avatar.png`).
- **Макет** на канвасе Claude: https://claude.ai/artifact/QWpPxUsmYCgKVYid3dpAuS
  (светлая и тёмная тема всех экранов, лист с логотипом). Ссылка приватная.

## Решения по дизайну (пользователь их уже выбрал, не откатывать)

1. Первый вариант (шрифт Unbounded, лаймовые бейджи, карточки) отклонён:
   «не должен быть похож на ИИ».
2. Нативный стиль настроек Telegram отклонён: «нужен современный, модерн».
3. **Текущий стиль**: шрифт Onest, монохром (чёрная главная кнопка в светлой
   теме, белая в тёмной), один синий акцент `#2F6BFF` / `#5B8CFF`. Крупные
   заголовки, превью в две колонки со скруглением 18px, чипсы, плавающая
   панель-«док». Лайм — только в логотипе. Без градиентов-подложек, свечения и
   эмодзи (из сообщений бота эмодзи тоже убраны).
4. Тёмная тема обязательна. Тема берётся из `Telegram.WebApp.colorScheme` и
   меняется по событию `themeChanged`.
5. Плавные анимации везде: FLIP при перестройке сетки, появление каскадом,
   шторки въезжают и уезжают. `prefers-reduced-motion` отключает анимации.
6. **Сначала макет, потом согласование, и только потом код.** Это касается любых
   визуальных изменений (анимации, экраны, заставки) и любой новой функции с экраном
   или сценарием в мини-аппе, в том числе бэкенда под неё: пока пользователь не одобрил
   макет, код не писать. Макет делать обычной HTML-страницей (артефакт),
   **не доской/холстом Design**, и в конце задавать вопросы, которые надо решить.
   Если непонятно, чего хочет пользователь, сначала уточнить, а не писать код.
7. **Заставка при входе — «Тихий вход»** (выбрана по макету из трёх): логотип проявляется
   за 0,24 с, держится минимум 0,45 с (`SPLASH_MIN` в `app.js`), затем гаснет за 0,27 с, а
   интерфейс выезжает. Показывается при каждом открытии, без перелёта логотипа.
   Открыто: тонкая обводка плитки логотипа в тёмной теме; показывать только раз в день?

## Как запускать

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env              # вписать BOT_TOKEN
./scripts/dev.sh                  # туннель cloudflared + бот; без cloudflared — бот без мини-аппа
.venv/bin/python -m app.demo      # только интерфейс, без токена: http://127.0.0.1:8080/?demo
```

- `scripts/dev.sh` ищет `cloudflared` в PATH или в `bin/` (папка `bin/` в
  `.gitignore`, бинарник скачивается отдельно). Адрес quick-tunnel меняется при
  каждом запуске, бот сам обновляет кнопку меню «Редактор».
- Демо на широком экране показывается в рамке телефона 390×844 с кнопкой смены
  темы. `?demo&inner` — без рамки.
- В Chrome у пользователя `localhost` принудительно уходит на HTTPS (запомненный
  HSTS), поэтому демо открывать по `http://127.0.0.1:8080/?demo`.
- Продакшен: `Dockerfile` (ставит `fonts-liberation` для титульника). Нужны
  переменные `BOT_TOKEN` и `WEBAPP_URL` (публичный HTTPS-адрес, который ведёт
  на порт 8080 контейнера), а `DATA_DIR` стоит вынести в том (volume).

## Проверено и не проверено

- Проверено: сборка PDF во всех 18 сочетаниях настроек, API (подпись, превью,
  порядок, поворот, сборка, титульник) — тестовым скриптом. Мини-апп — в
  браузере в демо-режиме, светлая и тёмная тема.
- Бот запущен у пользователя (@finconverter_bot), polling работает.
- **Не проверено**: мини-апп внутри настоящего Telegram через туннель
  (пользователь запускал `dev.sh` сам), деплой на хостинг. Тестов в репозитории
  нет: проверочный скрипт лежал во временной папке.
